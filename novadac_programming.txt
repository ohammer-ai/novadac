The following little program sends the given numbers to DAC 0 (=DACA) in a loop, with a short delay between each value. If connected to a synth module (VCO, voltage controlled oscillator) it will play four notes (A, F, D, E) in rapid succession.

; The data block starts at 000000

000000	001315		; 717 DECIMAL, GIVES 1.750 V
000001	001736		; 990 DECIMAL, GIVES 2.417 V
000002	001567		; 887 DECIMAL, GIVES 2.167 V
000003	001674		; 956 DECIMAL, GIVES 2.333 V
000004	177777		; -1 MARKS END OF SEQUENCE
…

; The code block start at 001000

001000	152400	SUB	2,2		; CLEAR AC2 (POINTER)
001001	072023	DOB	2,23		; SELECT DAC 0 (address 0)
001002	025000	LDA	1,0,2		; LOAD VALUE AT ADDRESS AC2 INTO AC1
001003	125415	INC#	1,1,SNR		; IS IT -1 (END OF DATA)?
001004	000774	JMP	.-4		; YES, START FROM BEGINNING
001005	065023	DOA	1,23		; NO, SEND TO DAC 0
001006	151400	INC	2,2		; INCREMENT POINTER
001007	126400	SUB	1,1		; LOOP 65536 TIMES FOR DELAY
001010	125404	INC	1,1,SZR
001011	000777	JMP	.-1
001012	000770	JMP	.-10		; CONTINUE LOOP
